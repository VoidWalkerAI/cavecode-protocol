# Historical founding material

`CaveCode_v1_FoundingCard.txt` is the Arcade Planet founding declaration and an
important early CaveCode artifact. It preserves the original five glyphs and
the spirit of the work.

It is historical evidence, not the ratified CaveCode specification and not the
sole authority for current repository state. Normative rules live under
`specs/`; current project truth lives in the root Master Project Map.
