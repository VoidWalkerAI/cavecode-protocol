# CaveCode Micro Teaching Pack (v1.0)

CaveCode is a plain-text map for humans and AI.

## Glyphs

- 🪨 locked/protected
- 🖍️ human-editable — the crayon
- 🔧 expandable/open work
- 🎮 behavior/flow
- 🌐 public-safe

## Block law

```text
🪨 BLOCK 1 — IDENTITY
🎮 BLOCK 2 — FLOW
🖍️ BLOCK 3 — SAFE SETTINGS
🔧 BLOCK 4 — NEXT EXPANSION
```

Number = address. Glyph = role. Title = subject. Use any number of blocks and
reuse glyphs when their role repeats.

## Repository law

A CaveCode-managed repository keeps one root-level
`PROJECT-NAME.cavecode.txt` as its read-first Master Project Map. Meaningful
state changes update that map in the same commit as the implementation.

The map tells a cold reader what the project is, what is true now, what is
protected, what is broken or unresolved, and exactly where to resume.
