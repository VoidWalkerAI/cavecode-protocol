# CaveCode Teacher Pack v1.0

For the maintained teaching contract, read:

- [`../teaching/full-teaching-pack.md`](../teaching/full-teaching-pack.md)
- [`../teaching/micro-teaching-pack.md`](../teaching/micro-teaching-pack.md)

The essential rule is:

```text
🪨 locked        🖍️ human-editable/crayon
🔧 expandable    🎮 behavior/flow
🌐 public-safe
```

Glyphs are semantic roles rather than fixed block positions. A CaveCode-managed
repository also keeps a root-level `PROJECT-NAME.cavecode.txt` Master Project
Map current in the same commit as meaningful implementation changes.
